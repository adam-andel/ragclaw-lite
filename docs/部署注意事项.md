# 部署注意事项（ERAG REPL 沙盒）

本文档说明 LLM 代码沙盒（`mcp/repl_mcp_server.py`）的身份与隔离相关部署要点。
**本项目为全新未上线项目，不兼容任何旧用户/旧方案**，因此下列设计均以"无历史包袱"为前提。

---

## 1. 身份密钥 `REPL_AUTH_SECRET`（强制开启，无单账户回退）

沙盒以**强制开启**的身份校验 + 每用户 UID 隔离运行，**不存在"未配置密钥即退化为单账户"的模式**。任何 `run_python / run_shell / run_javascript` 调用都必须携带由 Backend 签名的身份信封，否则直接被拒绝（错误码 `-32001`）。

- **密钥从哪来**：Backend 的 `ConfigManager` 在首次启动时若发现 `REPL_AUTH_SECRET` 为空，会用 `secrets.token_hex(32)` 自动生成一个强密钥，落库到 `system_settings`，并在安全读取时脱敏。
- **如何下发到沙盒**：Backend 启动时通过内部接口 `PUT /auth-secret`（仅容器内部网络可达、无宿主机端口映射）把密钥推给 `mcp-repl`，并以重试 + 每 60s 周期重推的方式兜底（应对沙盒容器重启）。
- **信封内容**：`{user, uid, exp, sig}`，其中
  `sig = HMAC-SHA256(secret, f"{user}|{uid}|{exp}")`，`exp=0` 表示不过期。
  `uid` 是**必填**且参与签名——沙盒据此无状态地降权到该精确 UID，无需查库，也杜绝了伪造 UID。
- **轮换（热操作）**：在系统设置页或使用 `PUT /api/config/repl-auth` 重新生成密钥后，Backend 立即把新密钥推给沙盒。已 spawn 的子进程、已落盘的 `user_u<uid>/<ws>` 目录**完全不受影响**；最多存在亚秒级认证抖动（旧签名被拒、新签名自愈）。
- **空密钥被拒**：`PUT /auth-secret` 收到空/非字符串密钥会返回 `400`，**绝不**以"禁用 auth"的方式处理——auth 始终开启。

> 注：`docker-compose.yml` 中的 `REPL_AUTH_SECRET` 环境变量**可选**：不设也能跑（Backend 自动生成并推送）；设了则作为初始种子。它永远不会用来"关闭 auth"。

---

## 2. 每用户 UID 分配（随机 + 数据库唯一约束）

每个用户拥有一个**专属 Linux UID**，代码在该 UID 下运行，工作目录 `chown` 给该 UID 且 `chmod 700`，实现跨用户不可互访。

- **分配方式**：创建用户时从 `[REPL_UID_RANGE_MIN, REPL_UID_RANGE_MAX)`（默认 `10000..110000`，容量 10 万）随机取一个 UID，与 `users.repl_uid` 列一起提交；若触发唯一约束冲突（`IntegrityError`），回滚并重试，封顶 `REPL_UID_ALLOC_RETRIES=10` 次，耗尽则报 `503`。数据库是唯一仲裁者，高并发下也正确。
- **可扩容、不影响既有用户**：只需调大 `REPL_UID_RANGE_MAX`，新分配走更宽范围，已有用户的 `repl_uid` 不变、目录不重映射、不丢文件，**无需迁移脚本**。
- **删除用户 = 先清目录，再释放 UID（cleanup 先于复用）**：Backend 在删除用户行**之前**，先调用 `mcp-repl` 的 `DELETE /user/<uid>`（需 `X-Repl-Auth` 头、路径穿越防护）删除其 `user_u<uid>` 目录；若沙盒不可达则**阻断删除**，杜绝"新用户抽到同 UID 读到残留文件"。
- **为什么不用哈希池/时间戳**：本设计为全新项目，直接采用"随机 + 唯一索引"的确定性隔离，不再保留旧的确定性哈希池（`sha256(user) % size`）或时间戳映射——那些方案存在概率性撞桶或删除后 UID 复用的跨租户泄露风险，且需要兼容旧用户时才考虑。

## 3. 速查表

| 操作 | 是否安全 | 说明 |
| --- | --- | --- |
| 轮换 `REPL_AUTH_SECRET` | ✅ 安全（热操作） | 目录与数据不受影响，仅亚秒级认证抖动 |
| 调大 `REPL_UID_RANGE_MAX` | ✅ 安全 | 不影响既有用户，无需迁移 |
| 删除用户 | ✅ 安全 | 目录先清、UID 后释放，无复用泄露 |
| 把 `REPL_AUTH_SECRET` 设为空 | ❌ 不允许 | `PUT /auth-secret` 拒绝空密钥，auth 始终开启 |
| 期望"单账户模式" | ❌ 不存在 | auth + 隔离为强制不变量 |
