# 其他说明

## 部署入口（nginx）

生产环境所有入站流量都经过 **nginx** 反向代理——它是唯一的对外入口。后端只在内部 `ragclaw` 网络监听 `:8000`（不发布到宿主）。开启 HTTPS 后 nginx 负责终结 TLS（在「设置 → HTTPS」里开启、粘贴证书 + 私钥，nginx 即热重载），否则以明文 HTTP 提供服务。详见 `nginx/` 目录与 `.env.example` 中的 `RAGCLAW_HTTP_PORT` / `RAGCLAW_HTTPS_PORT`。

## ⚠️ 单 worker 硬约束

 后端以**且仅以 1 个** uvicorn worker 运行（`--workers 1`）。RAGClaw 依赖若干**进程内单例**——LLM 并发信号量、内存 BM25 索引、答案缓存、每进程独立的 Chroma 客户端——**绝不可**被 fork 到多个 worker。切勿用 `--workers N` 覆盖启动命令；要扩容请增加容器数量（横向），而非单容器内 worker 数（纵向）。
