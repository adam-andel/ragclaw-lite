# 沙盒（REPL 沙箱）

Claw 的「动手」能力运行在一个**独立的、安全加固的沙盒**里——一个专门的 `mcp-repl` 容器加一个 `ragclaw-egress` 代理容器，二者接入一张**无外网路由的内部网络**（`ragclaw-internal`，`internal: true`）。它不只是个代码执行器，而是一套刻意隔离的执行环境，是 RAGClaw 的核心亮点之一。

- **三种执行模式**：`run_python` 以独立 **subprocess** 运行——`preexec_fn` 施加 RLIMIT 资源上限并将进程降权到该用户账号，脚本写在工作目录内、以 `HOME=workdir` 执行；执行前注入守卫：网络访问由 `REPL_NETWORK_POLICY` 策略管控（默认拦截 `deny`，仅在你选择 `allow`/`allowlist` 时才放开，见下），并把 `open`/`os.open`/`io.open` 限定在本工作区内。`run_shell` 以降权的每用户 `user_u<uid>`（经 `setuid`）运行 `/bin/bash`，工作目录为用户的 workspace，并把 `HTTP(S)_PROXY` 指向出站代理。`run_javascript` 在 Node.js `vm` 沙箱上下文里执行模块，`fetch` 可用且经代理出网。
- **按用户的隔离工作区**：文件存放于 `/app/workspace/user_u<uid>/`，位于专属**持久化**卷 `ragclaw_workspace`，按用户隔离且 `mcp-repl` 重启后仍在；任何需要离开沙盒的产出都经由后端的 `/api/workspace/download`（及 `download-zip`）代理、按同一用户路径交付。
- **出站流量由代理把关，且策略可调**：沙盒容器本身**没有直连外网的路由**——所有出站连接被强制经 `HTTP(S)_PROXY` 走 `ragclaw-egress`，由代理执行你选定的策略：`deny`（默认，全部拦截）、`allowlist`（仅放行你配置的域名）或 `allow`（完全放开，调试用）。也就是说沙盒从不会"悄悄联网"，开多少网由你决定。策略存于 `/repl-policy/repl_network_policy.json`，`PUT /policy` 即热更新。
- **真实身份 + 最小权限**：后端用 HMAC `REPL_AUTH_SECRET` 为每个请求签名；`mcp-repl` 分配一批降权 UID（默认 10000–110000），把子进程 `setuid` 到对应 UID 并 `chown` 其工作目录。鉴权强制开启——不存在匿名执行。
- **容器级加固**：根文件系统 `read_only: true`，`tmpfs /tmp` 供 shell/node 临时使用，`no-new-privileges`，自定义 `seccomp.json` 屏蔽危险系统调用，`cap_drop: ALL`（仅补回隔离所需的 `SETUID`/`SETGID`/`CHOWN`），并设内存 / 进程数上限。MCP 服务仅内部可达，不映射宿主端口。

> 沙盒代码分散在 `mcp/` 与 `egress/`：`mcp/repl_mcp_server.py`（可配置的多语言执行引擎，含网络策略裁决与降权执行）、`mcp/python_repl_mcp_server.py`（pandas/docx/pptx/matplotlib 等数据科学运行时）、`egress/egress_proxy.py`（独立出站代理 / DNS broker）、`egress/skill_secret_proxy.py`（SKILL API 密钥注入代理，`:9090`）、`seccomp.json`、`mcp/Dockerfile`（及 `mcp/Dockerfile.dev`）/ `egress/Dockerfile.egress` / `mcp/entrypoint.sh`。
